# KDP.Cool 插画师作品展示网站 - 设计规范文档

## 1. 项目概述

### 1.1 项目信息
- **项目名称**: KDP.Cool - 插画师个人作品展示平台
- **设计版本**: v1.0
- **创建日期**: 2024年
- **目标平台**: Web桌面端（主要），响应式适配移动端和平板端

### 1.2 设计目标
- 建立专业的插画师个人品牌形象
- 提供优秀的作品展示体验
- 促进潜在客户的咨询和合作
- 体现现代、简洁、艺术化的设计风格

## 2. 视觉设计规范

### 2.1 色彩系统

#### 主色调
- **主紫色**: `#667eea` - 用于主要按钮、链接和重点元素
- **深紫色**: `#764ba2` - 用于渐变效果和强调元素
- **渐变色**: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)` - 用于英雄区背景和CTA按钮

#### 中性色
- **深灰色**: `#1f2937` (gray-800) - 主要文本颜色
- **中灰色**: `#6b7280` (gray-500) - 次要文本颜色
- **浅灰色**: `#f9fafb` (gray-50) - 背景色
- **白色**: `#ffffff` - 卡片背景和主要背景
- **边框色**: `#d1d5db` (gray-300) - 表单边框和分割线

#### 功能色
- **成功色**: `#10b981` (green-500) - 成功状态和确认元素
- **警告色**: `#f59e0b` (amber-500) - 警告信息
- **错误色**: `#ef4444` (red-500) - 错误状态
- **信息色**: `#3b82f6` (blue-500) - 信息提示

### 2.2 字体系统

#### 字体族
- **主字体**: 系统默认字体栈 (Tailwind CSS 默认)
- **中文字体**: 优先使用系统中文字体
- **英文字体**: San Francisco, Helvetica Neue, Arial

#### 字体大小层级
- **超大标题**: `text-5xl` (48px) - 页面主标题
- **大标题**: `text-4xl` (36px) - 区块标题
- **中标题**: `text-2xl` (24px) - 卡片标题
- **小标题**: `text-xl` (20px) - 子标题
- **正文**: `text-base` (16px) - 主要内容
- **小字**: `text-sm` (14px) - 辅助信息
- **极小字**: `text-xs` (12px) - 标签和注释

#### 字重
- **粗体**: `font-bold` (700) - 标题和重要信息
- **半粗体**: `font-semibold` (600) - 次级标题
- **常规**: `font-medium` (500) - 按钮文字
- **正常**: `font-normal` (400) - 正文内容

### 2.3 间距系统

#### 组件间距
- **极小间距**: `space-y-2` (8px) - 紧密相关元素
- **小间距**: `space-y-4` (16px) - 相关元素组
- **中间距**: `space-y-6` (24px) - 区块内元素
- **大间距**: `space-y-8` (32px) - 主要区块间
- **超大间距**: `space-y-12` (48px) - 页面区块间

#### 内边距
- **小内边距**: `p-4` (16px) - 小卡片
- **中内边距**: `p-6` (24px) - 标准卡片
- **大内边距**: `p-8` (32px) - 大卡片和区块
- **超大内边距**: `py-20` (80px) - 页面区块垂直间距

### 2.4 圆角系统
- **小圆角**: `rounded-lg` (8px) - 按钮和小元素
- **中圆角**: `rounded-xl` (12px) - 卡片
- **大圆角**: `rounded-2xl` (16px) - 大卡片
- **超大圆角**: `rounded-3xl` (24px) - 特殊容器
- **圆形**: `rounded-full` - 头像和图标容器

### 2.5 阴影系统
- **轻微阴影**: `shadow-sm` - 导航栏
- **标准阴影**: `shadow-lg` - 卡片
- **悬浮阴影**: `shadow-xl` - 悬浮状态
- **深度阴影**: `shadow-2xl` - 模态框

## 3. 组件设计规范

### 3.1 导航栏
- **高度**: 64px (`h-16`)
- **背景**: 白色 + 轻微阴影
- **Logo**: 40px × 40px 渐变背景圆角容器
- **导航链接**: 中等字重，悬浮时紫色
- **CTA按钮**: 渐变背景，白色文字

### 3.2 按钮系统

#### 主要按钮
- **背景**: 渐变色 (`hero-gradient`)
- **文字**: 白色，中等字重
- **内边距**: `px-6 py-3` 或 `px-8 py-4`
- **圆角**: `rounded-lg`
- **悬浮效果**: 透明度变化 (`hover:opacity-90`)

#### 次要按钮
- **背景**: 透明
- **边框**: 2px 白色或紫色
- **文字**: 白色或紫色
- **悬浮效果**: 背景填充

#### 文字按钮
- **背景**: 透明
- **文字**: 紫色
- **悬浮效果**: 颜色加深

### 3.3 卡片系统

#### 标准卡片
- **背景**: 白色
- **圆角**: `rounded-2xl`
- **内边距**: `p-8`
- **阴影**: `shadow-lg`
- **悬浮效果**: 向上移动 + 阴影加深

#### 作品卡片
- **图片**: 16:9 比例，圆角
- **标题**: 大字号，粗体
- **描述**: 灰色文字
- **标签**: 小尺寸，浅色背景

### 3.4 表单系统

#### 输入框
- **边框**: 1px 灰色 (`border-gray-300`)
- **圆角**: `rounded-lg`
- **内边距**: `px-4 py-3`
- **焦点状态**: 紫色边框 + 外发光
- **占位符**: 灰色文字

#### 标签
- **字体**: 小号，中等字重
- **颜色**: 深灰色
- **间距**: 底部 8px

### 3.5 图标系统
- **图标库**: FontAwesome 6.4.0
- **尺寸**: 通常 16px-24px
- **颜色**: 继承父元素或指定颜色
- **间距**: 与文字间距 8px (`mr-2`)

## 4. 布局规范

### 4.1 网格系统
- **容器**: `max-w-7xl mx-auto px-6` (最大宽度 1280px)
- **网格**: 使用 Tailwind CSS Grid 系统
- **断点**: 遵循 Tailwind 响应式断点

### 4.2 响应式设计

#### 桌面端 (≥1024px)
- **导航**: 水平布局，完整菜单
- **网格**: 3-4列布局
- **间距**: 标准间距

#### 平板端 (768px-1023px)
- **导航**: 水平布局，可能折叠部分菜单
- **网格**: 2-3列布局
- **间距**: 适中间距

#### 移动端 (<768px)
- **导航**: 汉堡菜单
- **网格**: 1-2列布局
- **间距**: 紧凑间距
- **字体**: 适当调整大小

## 5. 交互设计规范

### 5.1 悬浮效果
- **按钮**: 透明度变化或颜色变化
- **卡片**: 向上移动 8px + 阴影加深
- **链接**: 颜色变化到紫色
- **图片**: 轻微缩放效果

### 5.2 过渡动画
- **持续时间**: 0.3秒 (`transition-all duration-300`)
- **缓动函数**: ease (默认)
- **属性**: transform, opacity, colors, shadow

### 5.3 状态设计
- **默认状态**: 标准样式
- **悬浮状态**: 视觉反馈
- **激活状态**: 按下效果
- **禁用状态**: 降低透明度，移除交互
- **焦点状态**: 外发光效果

## 6. 内容规范

### 6.1 图片规范
- **来源**: Unsplash, Pexels 高质量图片
- **格式**: JPG, PNG
- **质量**: 高分辨率，适合网页显示
- **比例**: 16:9 (作品展示), 1:1 (头像), 4:3 (其他)

### 6.2 文案规范
- **语言**: 简体中文
- **语调**: 专业、友好、自信
- **长度**: 标题简洁，描述详细但不冗长
- **格式**: 使用项目符号、编号等提高可读性

## 7. 技术实现规范

### 7.1 技术栈
- **HTML**: HTML5 语义化标签
- **CSS**: Tailwind CSS 3.x
- **图标**: FontAwesome 6.4.0
- **JavaScript**: 原生 JavaScript (必要时)

### 7.2 代码规范
- **HTML**: 语义化标签，合理的层级结构
- **CSS**: 使用 Tailwind 工具类，避免自定义 CSS
- **命名**: 使用有意义的 class 名称
- **注释**: 关键部分添加注释

### 7.3 性能优化
- **图片**: 使用适当的格式和尺寸
- **CSS**: 通过 CDN 加载 Tailwind
- **字体**: 使用系统字体减少加载时间
- **JavaScript**: 最小化使用，优化加载

## 8. 可访问性规范

### 8.1 颜色对比
- **文字对比**: 确保足够的颜色对比度
- **状态指示**: 不仅依赖颜色，还使用图标或文字

### 8.2 键盘导航
- **焦点指示**: 清晰的焦点状态
- **Tab 顺序**: 逻辑的导航顺序
- **快捷键**: 必要时提供快捷键

### 8.3 屏幕阅读器
- **Alt 文本**: 所有图片提供描述性 alt 文本
- **标签关联**: 表单元素正确关联标签
- **语义化**: 使用正确的 HTML 标签

## 9. 浏览器兼容性

### 9.1 支持的浏览器
- **Chrome**: 最新版本及前两个主要版本
- **Firefox**: 最新版本及前两个主要版本
- **Safari**: 最新版本及前两个主要版本
- **Edge**: 最新版本及前两个主要版本

### 9.2 降级策略
- **CSS Grid**: 提供 Flexbox 降级
- **现代特性**: 渐进增强方式实现
