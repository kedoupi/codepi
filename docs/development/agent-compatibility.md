# 多工具入口与兼容范围

流程与规则总入口见 [规范导航](README.md)。本文件只维护 omp、Codex 和 Claude Code 的项目入口与已知能力边界，不复制产品约束、任务模板或操作流程。

## 仓库入口

| 工具 | 共同规则入口 | 共享 skill 入口 | 能力边界 |
| --- | --- | --- | --- |
| omp | 根 `AGENTS.md`、目标目录的局部 `AGENTS.md` | `.agents/skills/`；原生发现不可用时直接读取 `SKILL.md` | 不假定未经验证的自动 skill 发现或专用命令 |
| Codex | 根 `AGENTS.md`、目标目录的局部 `AGENTS.md` | `.agents/skills/`；`$kdp-*` 只是语法便利 | `agents/openai.yaml` 只提供显示元数据，不改变流程 |
| Claude Code | `CLAUDE.md` 导入根规则，再读目标目录局部规则 | `.claude/skills/` 轻量入口导入 `.agents/skills/`；`/kdp-*` 只是语法便利 | 入口能力以当前客户端和配置为准，不把自动发现当作验收证据 |

三者共用根规则、局部规则和 `.agents/skills/`；规则写入归属文档，工具入口只做引用。原生 skill 不可用时，按任务直接读取对应共享 `SKILL.md`。不维护其他客户端的专属流程页；仓库中已有的其他入口文件仍按其自身兼容要求保留。

## 日常使用

按[开发工作流的日常入口](agent-workflow.md#日常怎么用)操作：先核实 checkout、基线和已有改动，再读取根规则、开发导航、目标局部规则及适用 skill。工具差异不改变项目边界、授权要求或验证标准。

## 已知边界

该记录只覆盖当时的工作区、客户端版本和配置，不是持续兼容性保证。共享文件引用和脚本回归不能替代实际会话测试；客户端版本、项目可信状态、用户配置和 skill 缓存可能改变加载行为。无法读取仓库或执行检查的工具不能声称已完成开发或验证。

本地检查使用 Node、Git 及各应用已有包管理器，不依赖某家模型 API。按[开发工作流](agent-workflow.md)执行 `check.mjs` 预览和运行；UI、真实授权、远程资源、生产数据和发布仍需独立验收。
