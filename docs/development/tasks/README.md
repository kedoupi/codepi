## 使用约定

- 新增长任务或跨会话交接时新增 `YYYY-MM-DD-topic.md`；小修复只在回复中交付。
- 状态改变时更新本表；完成任务只移动到档案索引，不复制完整日志。
- 每个事项链接最新证据；无法确认线上状态时明确写“未核验”，不把旧快照当实时状态。
- 记录不包含凭证、Cookie、私人业务数据或完整邮件内容。
