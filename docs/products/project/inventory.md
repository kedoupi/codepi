# project 功能清单

只读调研，源码根 `~/Coding/codepi/apps/project`（下称 `P/`）。行号取自当前工作区。

## 概览

- 定位：个人「项目工作台」，把各仓库推上来的待办快照、要你拍板的事、分支、交接、变更汇成一处看；网页只允许「今天」挑选/退回、池子删除、「你的」事项标完成，不编辑待办内容（`P/AGENTS.md:4`）。
- 用户：只有主人本人（SSO 校验 `subject === "kdp-owner"`，`P/worker/auth.ts:14-18`）；另有 AI 助手经 MCP 读写今天。
- 入口：project.codepi.app（桌面侧栏 + 手机底部 2 标签）。
- 技术形态：Svelte 5 单页（`P/web/src/App.svelte`，自写 pushState 路由）+ Hono Worker（`P/worker/app.ts`）+ D1；机器推送走 `POST /api/ingest/:project`（Bearer 令牌）；MCP 经命名 RPC `ProjectMcp.execute/summary`，不开公网路由（`P/worker/mcp.ts:61-74`）；CSP 禁内联 style、纯文本渲染。

## 日常使用流与体验疑点（推断）

主流程（推断）：早上开窗，助手 `today_get` 并 `today_pick` 一版 → 主人打开今天页，看「你的」「建国的」→ 对池子里要自己做的点「放进今天」、不做的「删除」→ 「你的」做完点「完成」，「建国的」合并后由仓库推送自动移到做完 → 晚上在「动态」看当天/本周完成、上线、查过。偶尔到项目页看待办构成、分支、交接，或新增项目、换令牌。

疑点：
1. 手机端缺项目入口：侧栏隐藏后底栏只有「今天/动态」，项目页、添加项目、退出登录在手机上都够不着（`style.css:277-283`），而画板手机稿画了 4 标签。
2. 今天页的任务标题不可点，无法开抽屉看「是什么/不做会怎样/建议」；抽屉只能从项目页卡片打开（`Today.svelte` 无 `onOpen`；`App.svelte:169` 未传入）。要拍板的事缺少上下文，要先去项目页找。
3. 池子「删除」一键直达、无确认无撤销；与「放进今天」紧挨，手机上两个按钮等宽并排（`style.css:370-372`），易误触。
4. 今天页读取失败只有文字没有重试，操作失败提示不自动消失、没有重试，需整页刷新。
5. 今天页没有跨天提示：「昨天没做完」只是小字；做完栏没有时间；只能看到当天完成，看更早要去「动态」。
6. 「动态」页名与内容（工作日报）不一致，AGENTS 也明说「页卡名为动态但内容是工作日报」；`/api/log` 遗留接口无人用。
7. 项目状态切换（含归档）一点即存、无确认，归档后该项目从侧栏消失，且无「已归档项目」入口回看。
8. 无令牌时按钮仍写「重新生成推送令牌」，确认文案提到「旧令牌失效」，对新项目有误导。
9. 池子有「查过 N 次」信息但无入口看检查结论原文（只在动态页「查过」块里有 note）。
10. 项目配色按注册顺序取模 5 个 slot，项目超过 5 个后颜色会重复（`format.ts:68-71`）。
