# GU 投资 功能清单

> 源码根：`~/Coding/codepi/apps/gu`。行号均为 2026-11-07 当时读到的版本。以下文件名省略前缀：`web/src/` 简写为 `W/`，`worker/` 简写为 `K/`。

## 概览

- 一句话定位：kedoupi（codepi）旗下的私人投资工作台，单账户所有者；展示持仓、风控、报告、数据来源，并支持在线维护账户、流水、规则、资料与报告。
- 用户：只有张老板本人（统一登录固定发验证码到本人邮箱；`K/mcp.ts` 主体只接受 owner）。
- 入口域名：`gu.codepi.app`（见 `README.md` 第 3 行；统一登录经 `auth.codepi.app`）。
- 技术形态：Cloudflare Worker `codepi-gu`（Hono）+ Workers Static Assets（`run_worker_first = true`，静态资产也先过会话门）+ D1 + R2 `MATERIALS`；前端 Svelte 5 + Vite 单页，hash 路由；CSP `style-src 'self'`，图表几何靠 `data-*` + CSSOM 应用。
- 是否已上线：推断为已部署。`wrangler.toml` 含生产变量（`ENVIRONMENT=production`、`SSO_ENABLED=1`）。但 README 明说「源码存在不表示生产已启用」，线上工作台（`gu_workspace_head`）是否已「首次确认保存」从代码读不出，需线上读回。
- **两种形态（改版最大风险点）**：
  - 旧看板模式（`/api/dashboard` 返回同步批次）：导航为「总览 / 持仓与风控 / 研究与报告 / 数据状态 / 线上工作台」，数据来自本地脚本上传的快照，只读。
  - 线上模式（工作台首次保存后，`session.online` 有值）：导航换成「账户与持仓 / 成交流水 / 投资规则 / 资料库 / 研究报告 / 版本与导出」，旧看板（含风控、图表、日历）整体不再显示，旧上传接口返回 409。`W/App.svelte:20-29`、`K/data.ts:101-141`。
  - 两种形态下的页面集合不同，设计稿必须两套都画，且说明切换条件。

## 日常使用流与体验疑点（推断标明）

日常流（推断）：
1. 早上打开，登录（统一登录，7 天内免登）。
2. 旧看板模式：看总览的风险提醒与「当前需要关注」，必要时点图表进持仓页；读最新报告；到数据状态页确认批次与日历。
3. 线上模式：直接落在「账户与持仓」，更新估值/余额，记交易，更新规则与报告，预览后保存；导出备份。

体验疑点：
- **两套信息架构共存**（事实，`App.svelte:20-29`）：同一路径 `#status`、`#reports` 在两种形态下含义完全不同，`#overview` 在线上模式被视作 workspace。改版若合并两套，需确认旧看板是否还要保留。
- 线上模式下**风控、图表、日历、市场行情全部消失**（事实：README「不再显示旧快照中的风控结论」）。启用线上账户等于功能降级，是否是用户预期需确认。
- 「等待核实」说明写死港股股数、GOOGL 等具体内容（`Status.svelte:84-86`），属硬编码业务文案，不随数据变化（事实）。
- 登录页本地验证码形态里有一个写死的遮蔽邮箱展示（`Login.svelte`，此处不抄录），生产不走该分支。
- 手机端：侧栏变底部 2x3 六格导航（旧模式 5 项，线上模式 6 项），推断旧模式下有一格空；表单页在手机上的实际可用性（大量长表单、多字段）只读了断点，没有实测。
- 「预览并保存」要求每次改动都过预览，再点确认，两步；资料库页没有保存栏，上传立即生效（事实）。
- 功能入口只在顶栏有「刷新」和「退出」，没有任何全局搜索；报告搜索仅在旧看板报告页（事实）。
- 线上模式报告页是编辑表单，没有只读阅读布局（只能展开「阅读报告」折叠）——推断阅读体验弱于旧看板的报告详情（章节目录、返回顶部在线上模式都没有）。
- 旧看板图表与日历区块用 `{@html}` 注入（来自受信任批次，已转义），改版需保持 CSP 与 CSSOM 约束（`AGENTS.md` 规定）。
